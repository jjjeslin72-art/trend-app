# 트렌드 레이더 📡

브랜드·가게 이름만 넣으면 AI(구글 Gemini + 구글 검색)가 조사해서 보여주는 **개인용** 안드로이드 앱.

- 🔁 스테디 모델 10 · 🔥 2026 주력 10 · 🆕 고른 나라의 지금 신상 10 · 🎬 영상 · 📎 출처
- 모델마다: 사진 여러 장(앞·뒤·디테일), 원단 성분 + 봉헤치로 원단 이름(포르투갈어), 색·핏·가격, 🇧🇷 브라질 판매 점수, 🌍 여러 나라 동시 출시
- 봉헤치로 작은 가게도 상호만 넣으면 인스타·사이트·왓츠앱 카탈로그를 찾아 조사 (같은 이름이 여러 곳이면 고르기)
- 🔔 새 상품 알림: 하루 한 번 확인
- 👗 Vitrine AI 앱으로 사진 보내기

## 구조
- 화면 전부: `app/src/main/assets/index.html`
- 안드로이드: `MainActivity.kt`(사진·페이지 가져오기, 저장·공유), `TrendWorker.kt`(새 상품 알림), `Net.kt`
- `main`에 올리면 **Actions → Releases**에 `TrendRadar-번호.apk`가 생김
- AI 키: GitHub 비밀값 `GEMINI_API_KEY` (없으면 앱 ⚙️ 설정에서 직접 입력). **개인용이라 남에게 APK를 주지 말 것** (키가 들어 있음)
- 남의 사진은 앱에 저장하지 않고 원래 주소에서 보여줌 (개인 공부용)
